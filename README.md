# UserHub — Full-Stack User Management Application

UserHub is a classroom full-stack web application built with Spring Boot, ReactJS, and an H2 database. It demonstrates registration, login, token authentication, role-based access, a protected dashboard, profile editing, admin user listing, and server-side logout.

## Technologies

- Java 21 and Spring Boot 4.x
- Maven
- Spring Web MVC, Spring Data JPA, Jakarta Validation
- H2 in-memory database
- ReactJS, Vite, React Router, Axios
- Lucide React icons

## Requirements

Install:
- JDK 21 or newer
- Node.js LTS and npm
- Maven (or use the Maven wrapper generated by Spring Initializr)
- IntelliJ IDEA or VS Code

## Backend setup

1. Open a terminal in the `backend/` directory.
2. Confirm Java is available: `java -version`.
3. Run the application:

   Windows (if Maven is installed):
   ```bash
   mvn spring-boot:run
   ```

   macOS/Linux:
   ```bash
   mvn spring-boot:run
   ```

4. The API runs at `http://localhost:8080`.
5. H2 console: `http://localhost:8080/h2-console`
   - JDBC URL: `jdbc:h2:mem:userhubdb`
   - User Name: `sa`
   - Password: leave blank

If you generated a Maven wrapper, you may use `mvnw.cmd spring-boot:run` on Windows or `./mvnw spring-boot:run` on macOS/Linux.

## Frontend setup

1. Open another terminal in `frontend/`.
2. Install packages:
   ```bash
   npm install
   ```
3. Start Vite:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:5173`.

Keep the backend and frontend terminals running at the same time.

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/api/auth/register` | Register a USER |
| POST | `/api/auth/login` | Log in and receive a token |
| POST | `/api/auth/logout` | Invalidate the current token |
| GET | `/api/dashboard` | Get the current user's dashboard |
| GET | `/api/dashboard/users` | ADMIN-only list of users |
| PUT | `/api/users/me` | Update the current user's full name |

For protected requests, include this header:

```text
Authorization: Bearer YOUR_TOKEN
```

## Testing the application

1. Open `http://localhost:5173/register`.
2. Register a normal user with a valid name, email, and password (at least 8 characters).
3. Log in at `/login`.
4. Confirm the dashboard loads and refresh the page.
5. Open My Profile and update the full name.
6. Log out, then try to open `/dashboard` directly.
7. Log in using the default ADMIN account.
8. Open Admin Users and confirm the registered accounts are displayed.
9. Try the admin endpoint with a USER token; it should return `403 Forbidden`.
10. Try a protected endpoint without a token; it should return `401 Unauthorized`.
11. Log out and reuse the old token in Postman; it should return `401 Unauthorized`.

## Classroom implementation notes

This project follows the supplied lab's learning approach: SHA-256 password hashing and UUID tokens stored in a server-side `ConcurrentHashMap`. These are educational examples, not production security recommendations. The H2 database and session map reset when the backend restarts.
